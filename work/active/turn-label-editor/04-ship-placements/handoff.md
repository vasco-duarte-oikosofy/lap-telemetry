## The collision rule (important)

A placement is honoured **unless** its label would overlap one already placed or
sit outside the widget; then that corner goes back to the automatic rule. This
kept Paul Ricard ELMS shippable: at 400 px the driver's layout overlapped twice
(Signes/Garlaban/Lac) where the widget's font is bigger relative to the map than
in the editor. At 600 px it is exactly the driver's layout.

Consequence to know: **what ships is the driver's layout, not necessarily their
exact pixels at every widget size.** The editor + preview tab show both.

## Notes / next

- **Restart TinyPedal (or reload the track map widget)** to pick up the new
  packaged files and the new settings key. Existing settings files get the
  default `use_track_orientation: true` on load.
- The rotation a track ships is only used while `display_orientation` is 0. If you
  want a *different* rotation for a track that ships one, set the widget's
  `display_orientation` to any non-zero value (it then wins), or turn
  `use_track_orientation` off to ignore packages entirely.
- 15 other tracks still ship `s_frac` only — their labels are placed by the rule.
  Place them in the editor, add to `turn-label-presets.json`, re-run the exporter.
- The 400 px Paul Ricard overlap is worth a second pass in the editor at
  **400 px in the preview tab** (not 600) if the driver wants their exact layout
  at the default widget size.

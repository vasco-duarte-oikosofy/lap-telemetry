# Catalog Index

This repository is organized by purpose. Start here, then follow each folder's `README.md` for details.

## `product/`

Production/final code and product-owned assets. This is the candidate subtree for future extraction into a standalone GitHub project or submodule.

See: [`product/README.md`](product/README.md)

## `dev/`

Development-only tooling, tests, fixtures, and tracked development inputs. `sessions/` belongs here in a later slice because it is tracked development data, not local output.

See: [`dev/README.md`](dev/README.md)

## `docs/`

Stable project documentation and specs that should outlive a single implementation mission.

See: [`docs/README.md`](docs/README.md)

## `work/`

Active, completed, and archived implementation missions. Mission folders use `PLAN.md` plus one folder per vertical slice.

See: [`work/README.md`](work/README.md)

## `vendor/`

Third-party or externally sourced code, including submodules and shared-memory dependencies.

See: [`vendor/README.md`](vendor/README.md)

## `var/`

Untracked generated or local output such as test reports, screenshots, and temporary files. Tracked development data does not belong here.

See: [`var/README.md`](var/README.md)

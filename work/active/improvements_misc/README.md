A collection of small improvements in these folders. 
Each folder here represents one slice of work with a specific format
./PLAN.md - the list of slices in this work, listing all the slices and their status
[slice name]/prompt.md - the work handoff prompt that instructs the agent on what to do for that particular slide
[slice name]/learnings.md - the collection of lessons learned during the execution of this slice, added after the work is completed

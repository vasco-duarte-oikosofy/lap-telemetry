# var/

Generated local output belongs here and should stay untracked except for orientation files like this README.

Use this folder to isolate files produced by tests, screenshots, ad hoc runs, and temporary debugging commands.

## Belongs here

- Test reports.
- Screenshots generated by tests or debugging.
- Temporary logs and scratch output.

## Does not belong here

- Tracked development data such as `sessions/`.
- Production/final code.
- Stable documentation.
- Mission plans, handoffs, learnings, or artifacts that belong in `work/`.

No generated output is moved into this folder in the current slice.
